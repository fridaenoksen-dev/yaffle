# Yaffle – logo

**Vaffelplan:** vaffelruta er også en plan, med et hjerte i midten.

## Filer

| Fil | Bruk |
|---|---|
| `yaffle-horizontal-green.svg` | Hovedlogo: symbol og navn side om side |
| `yaffle-stacked-green.svg` | Når plassen er høy og smal |
| `yaffle-symbol-green.svg` | Symbolet alene, fra 40 px og oppover |
| `yaffle-symbol-small-green.svg` | Forenklet 2×2-versjon under 40 px (favicon, toppmeny) |
| `yaffle-app-icon.svg` | App-ikon: kremhvite ruter på grønn bakgrunn |
| `-black` / `-white` | Én farge, til trykk og mørk bakgrunn |

Favicon, app-ikoner og manifest ligger i rotmappen (`favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `maskable-512.png`, `site.webmanifest`).

## Skrift

«Yaffle» er satt i **DM Serif Display** (SIL Open Font License, tillatt i logo) og tegnet ut som former, så filene trenger ikke skriften.

## Regler

- **Luft rundt:** minst én rute (bredden på en vaffelrute) på alle sider.
- **Minste størrelse:** fullt symbol 40 px. Under det: bruk 2×2-versjonen.
- **Bakgrunn:** grønn logo på lys bakgrunn. På mørk bakgrunn eller foto: hvit versjon.
- **Ikke** strekk, vri, legg skygge på, bytt farge på hjertet eller fjern hjertet.
- Rutene er hull, ikke hvite felter: logoen viser bakgrunnen gjennom.

Varemerke er ikke sjekket. Gjør et søk før logoen brukes kommersielt.
